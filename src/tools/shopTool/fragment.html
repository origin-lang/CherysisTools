图片加速（共享缩略图）

在这台「主机」上点一次，其他电脑翻商品、开画册就会快很多。

原理：原始图片有几 MB，缩略图只有几十 KB。客机第一次看到某个商品时，本来要先把原图从共享盘整张读过来再缩小， 慢就慢在这一步；预先把小图放进共享目录后，客机直接读小图。
· 只对新图/改过的图有用得着的工作量：已经缩过的会跳过，重复点只是扫一遍。
· 只写共享目录里的图片缓存，不碰数据库、也不动原图；图片改了或编号改了，那一个编号的缓存会自动作废重缩。
· 需要「数据存储目录」指向共享盘（见上面一行）；只在 VS Code 默认目录、没有第二台机器时会提示无处可放。
· 跑的时候下方「运行日志」会报进度（上千张图可能要几分钟），期间可以照常用面板。

商品列表操作提示

表头下小框可筛选对应列（编号框可输 A1~A33 范围）；单击单元格框选，Ctrl+C/X/V 复制/剪切/粘贴该格、Esc 取消框选；双击单元格编辑（回车或点击别处即保存）；右键可剪切/复制/粘贴、复制整行/删除整行

录入与命名规范

  • 编号统一 1 个字母 + 数字（3 位补零，最多 4 位、≤9999）：L7→L007、A7→A007、L1044 不变；纯数字默认补 A；每前缀编号独立（A001 与 L001 可并存）
  • 图片放 {图片根目录}/{编号} 文件夹；上传会自动按 {编号}_时间戳.jpg 改名（如 L76_20260905103015.jpg），文件夹里最早一张当封面
  • 历史遗留的 X / R / 裸号不新建，粘贴解析遇不到编号就进「未匹配」列表
