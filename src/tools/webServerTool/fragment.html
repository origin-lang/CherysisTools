和 VS Code 面板对一对
网页版服务和 VS Code 面板是两份各自存的配置、互不相读（网页服务端只认 cherysis-server.config.json），所以改了一边另一边不会跟。上面不一致时两边都要改： 网页版这边改完「保存配置」，面板那侧去设置里改（数据目录 cherysis.storageDir、图片目录 cherysis.shopTool.imageDir）。数据目录必须两边都指到同一份库，否则等于对着另一个库录数据。

几个容易踩的点
· 数据目录 / 图片目录必须是这台机器读得到的路径；本机缓存要放本机盘（放共享盘会又慢又多人互踩）。
· 改完配置要重新「启动」才生效（端口改了尤其明显）。
· 起服务前记得放行防火墙，否则这台自己能开、手机连不上。
· 别一边开着 VS Code 工具面板改数据、一边开着网页版改同一份库：电脑版的撤销是整库回滚，会把另一边刚写的一起抹掉。
