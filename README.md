# Cherysis

VS Code 工具箱扩展，主打**商品店铺管理**：商品档案、每日销售、按月对账、直播排品一站式搞定。

## 商品店铺管理（shopTool）

五个页签：

| 页签 | 作用 |
|---|---|
| 商品管理 | 商品档案、图片、导入/导出、批量操作、画册 |
| 每日销售 | 当日卖货录入、批量粘贴、销售趋势图 |
| 分析·月报 | 按月对账、封账、净利润 |
| ⭐ 直播排品 | 画册星标选品 + 九宫格排图 |
| 规则与设置 | 售价规则、图片目录、数据库备份/恢复 |

### 商品管理

- **列表 / 画册**两种视图；「字段显示」勾选哪些列，**列表、复制、导出、导入全跟随**（所见即所得）；
- **库存**：补货入库自动 +，每日销售卖出自动 −（退款加回）；觉得不准就直接**双击库存列改成实际清点数**（每月盘点就这么改）；有货就能算钱，忘算了以手动清点为准；
- **导入**：整列粘贴，编号永远是第 1 列，Tab/空格/逗号分隔，只贴编号也能建（其余走默认），已有编号则覆盖更新（只更新本行列里填了的字段）；库存/销量/状态是自动统计列不导入；
- **导出 Excel**：按当前筛选结果导出；
- 图片按 `{图片根目录}/{编号}` 文件夹管理，上传自动改名 `{编号}_时间戳.jpg`，最早一张当封面；
- 批量：勾选后批量上架/下架、复制选中、删除（删除前自动备份）。

### 每日销售

- 快速录入：编号 + 卖出/退款件数，当天重复按「累加 / 覆盖 / 跳过」模式处理；
- **批量粘贴**：直接整列粘贴 `编号 卖出 退款`（Tab/空格/逗号都行）；
- 销售趋势：按天/按月柱状图，悬停看净售与退款。

### 分析·月报

三步：选月份 → 填到账与支出 → 锁定封账。

手填：**到账收入 / 本月进货支出 / 杂项支出（快递、氧化袋等）**。**期末库存金额自动算**＝各品（库存数量 × 进价）之和，想让它准就月底先双击盘点改库存再保存。

利润区给**三种口径**（同一组手填数换算）：现金流（钱袋子）、净资产口径（含库存）、净利润（结转期初，存档口径）。期初库存自动＝上月期末库存。

### ⭐ 直播排品

- 画册卡片点 ⭐ 加入备选，点备选自动填进九宫格（也可手填，自动补零校验）；
- 格子颜色：🟩 有效 / 🟥 编号不存在 / 🟧 重复；
- 一键生成全部九宫格图片，也可单组「生成这组」。

### 规则与设置

- **售价规则**：按等级配置公式（`cost=进价`）+ 尾数策略，保存后一键重算所有商品售价；
- **完整名称模板**：`{name}{category}{series}{grade}{code}` 变量，实时预览；
- 库存预警阈值（在售且 ≤ 阈值标红提示补货）；
- **数据库备份 / 恢复**：备份生成完整 `.db` 快照（含 WAL 未落盘数据）；恢复用所选备份整体替换当前数据（操作前自动先备份一次）。

## 数据在哪

- 数据库 `shop.db` 默认在 VS Code 全局存储 `…\globalStorage\Faye.Cherysis\`；
- 可设置 `cherysis.storageDir` 改到自己的目录（改完重启窗口生效，改目录前先备份）；
- SQLite 为 WAL 模式，**手动拷贝数据库要把 `shop.db` + `shop.db-wal` + `shop.db-shm` 一起拿**；
- 每天自动备份（保留 14 份）、每个删除/关键操作前前置备份（保留 20 份），都在 `{存储目录}/backups/`，反悔就到「从备份恢复」选文件。

## 使用

`命令面板 → Cherysis: 打开工具面板` 或侧边栏启动工具面板。

详细操作说明见 [docs/shopTool-manual.md](docs/shopTool-manual.md)。
