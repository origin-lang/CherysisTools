## 一、30 秒版（先跑起来再说）

1. 双击项目根目录的 **`启动网页版.cmd`**
2. 窗口里会打印一行 **手机访问：`http://192.168.x.x:669`**
3. 手机连**同一个 Wi-Fi**，浏览器打开那个地址
4. **这个窗口别关** —— 关掉就等于停服务，手机上就打不开了

现在仓库里已经有一份**指向演示数据**的配置，所以第 1 步双击就能用，**什么都不用改**。

## 二、启动（详细版）

### 前提

- 装过 Node（在项目目录里 `node -v` 有版本号）
- 跑过一次 `pnpm install`（项目里已有 `node_modules` 的话就跳过）
- 改过 `src` 下的 `.ts` 就要 `pnpm run compile`（启动器发现没编译过会提示你）

### 双击启动

双击 **`启动网页版.cmd`**。它会切到项目目录、检查配置文件、必要时先编译，然后启动服务。

**你会看到的输出**（实测样例，路径/地址随你的机器变）：

```
配置文件：C:\...\cherysis-tools\cherysis-server.config.json

⚠️ 注意：这份配置指向的是**演示/测试数据**（tmp-web-test），不是正式商品库。
   想先用假数据把功能点走一遍：就这样用，什么都别改。
   想换成你自己的库：把 cherysis-server.config.json 里的 storageDir / imageDir
   改成真实路径再重启（详见 docs/网页版-上手与自测.md 第四节）。

🔧Cherysis 网页版服务已启动
   数据目录：C:\...\cherysis-tools\tmp-web-test\data
   图片目录：C:\...\cherysis-tools\tmp-web-test\images
   本机缓存：C:\...\cherysis-tools\tmp-web-test\cache
   本机访问：http://localhost:669
   手机访问：http://192.168.1.40:669
```

那行"⚠️注意"是启动器加的：**它会告诉你现在动的是演示库还是正式库** —— 这件事最不能靠猜。

### 命令行启动（调试时用，等价）

```bash
pnpm run compile                                    # 改过 .ts 才需要
node scripts/serve-web.cjs                          # 等价于双击启动器
pnpm run serve                                      # 直接跑服务（读当前目录的配置文件）
```

### 停止

关掉那个窗口，或者在里面按 `Ctrl+C`。

### 不想每次都双击

任务计划程序 → 触发器"登录时"（要"没人登录也跑"就选"计算机启动时"+勾"不管用户是否登录"）→
程序 `node.exe`，参数 `out\server\index.js --config=配置文件的绝对路径`，起始位置填项目目录。

## 三、手机连上去

| 步骤 | 做什么 |
| --- | --- |
| 1 | 手机连**同一个 Wi-Fi**（和跑服务那台机器同网段） |
| 2 | 打开启动窗口里"手机访问"那个地址，例如 `http://192.168.1.40:669` |
| 3 | 存成书签/加到主屏幕，以后直接点 |

**连不上，按顺序排查**（90% 是前两条）：

1. 服务还在跑吗？（那个黑窗口没被关掉？浏览器打开 `http://localhost:669/api/ping` 通不通）
2. **防火墙放行端口**（需管理员 PowerShell，助手工具无权提权）：
   ```powershell
   New-NetFirewallRule -DisplayName "Cherysis 网页版" -Direction Inbound -Protocol TCP -LocalPort 669 -Action Allow -Profile Private
   ```
3. 手机和主机在同一个 Wi-Fi 吗？（手机别开着流量/VPN；公司网可能隔离设备）
4. 主机 IP 变了？看启动窗口里那行"手机访问"，以它为准。
5. 页面打开是空白/一直转圈：看启动窗口有没有报错。

## 四、换成你自己的真实数据

**一句话**：把 `cherysis-server.config.json` 里的 `storageDir` / `imageDir` 改成本机真实路径，重启。

1. **先备份** `shop.db`（插件本身有自动备份 + 操作前备份，双保险更稳）
2. 打开根目录的 `cherysis-server.config.json`（没有就从 `cherysis-server.config.example.json` 复制一份改名）
3. 改这三行：
   ```json
   {
     "storageDir": "Z:\\你的数据目录",
     "imageDir": "Z:\\商品图片",
     "cacheDir": "C:\\Users\\你\\cherysis-cache",
     "port": "666"
   }
   ```
   - `storageDir` = `shop.db` 所在目录；`imageDir` = 商品图片根目录（每个商品一个子文件夹，按编号命名）
   - **`cacheDir` 必须是跑服务这台机器的本机盘**，别指共享盘（慢，多机还会互相踩）
   - `port` 随便（默认 13800，你们之前用 666，演示配置用的 669）
   - 路径要么是**这台机器**上的本机盘，要么是它能访问的共享盘（`Z:\...` 或 `\\主机名\共享名\...`）
4. 重启启动器。窗口里那行"⚠️注意"消失、变成"数据目录：Z:\... ← 请确认这是你的正式库"，就说明切过来了。

> 服务器开在**哪台机器**上都可以，但记住：所有路径都是按**那台机器**解析的，
> 那台机器关机/休眠网页就打不开，读图也走它到共享盘的网络。

## 五、自测清单（演示数据上就能全走一遍）

### 5.1 基础功能（确认"能用"）

| # | 动作 | 预期 |
| --- | --- | --- |
| 1 | 手机打开地址 | 看到商品画册（卡片上是"进价 → 售价"和库存） |
| 2 | 点顶部「列表」 | 变表格；**往下滚**时表头（编号/名称/进价…）一直钉在顶上 |
| 3 | **改一个值**：手机上**快点两下**那一格（或慢慢点两下）；电脑上**双击**那一格 | 底部弹出一个输入框；改完按回车（或点保存）。**等级**那一格弹出来的是一列可点的等级（点一下就定），不是系统下拉框 |
| 4 | 鼠标停在某一格上（电脑） | 悬浮提示显示**这一格的内容**（名称那列被省略号截掉的长名字，这样能看到全称） |
| 5 | 点某行的**编号** | 进详情：宽屏（≥820px）从**右边滑出**、列表留在左边；手机上整屏 |
| 6 | 详情页「📷 传图」 | 相册/拍照选一张 → 上传后详情页多一张 |
| 7 | 详情页点多张图里的第二张 | 大图里出现 **‹ ›** 和「2 / 3」，点箭头左右切（电脑上还能按 ← → 翻、Esc 关） |
| 8 | 详情页「等级」下拉 | 在「名称」下面；改等级后**售价会按新规则重算**（那一格显示"自定义"的商品，下拉里也是"自定义"） |
| 9 | 「＋ 新建」 | 宽屏也是**右侧滑出**（列表留左边，可以边看边建）；手机上整屏 |
| 10 | 顶部漏斗（筛选） | 宽屏**从右边滑出**（列表留在左边，改条件能看着它变）、有「关闭」；手机仍在当前屏内展开；**点面板外面任意位置自动收起**；Esc 也能关 |
| 11 | 顶部「画册 / 列表」切换 | 鼠标悬浮时只是轻微压暗，**不会整块变白** |
| 12 | 点顶栏空白处（宽屏、抽屉开着时） | 抽屉收起（点商品卡片是换成那一件，点可改的格子是就地改，都不会收起） |
| 13 | 顶部 ⚙ | 规则与设置（**只读**）能打开 |
| 14 | 底部「日志」 | 能看到刚才那些动作的日志 |

### 5.2 实时推送（这一轮新做的，值得专门验）

> 想在同一台电脑上验"两端同步"：**开两个不同的浏览器**，或者一个正常窗口 + 一个**隐私/无痕窗口**。
> 同一个浏览器的两个标签页**现在也可以**（每个页面有自己的身份），但**别用同一个标签页刷新来验**。

| # | 动作 | 预期 |
| --- | --- | --- |
| 1 | 电脑浏览器开一个，手机也开一个（或电脑上开两个不同浏览器） | 两边都看到同一份商品表 |
| 2 | 手机上改一条的售价 | **电脑那边不点刷新就变了** |
| 3 | 电脑上用**VS Code 插件版**改一条（或删一条） | 手机底部冒出 **「🔄 有改动」**；点它 → 数据变成最新 |
| 4 | 看底部那条细条右边的**连接灯** | 绿色 + "已连接" |
| 5 | 把启动窗口关掉（停服务） | 灯变红 + 日志里出现「已断开」 |
| 6 | 再把服务启动起来，等几秒 | 灯自己变回绿色，不用手动刷新页面 |
| 7 | 手机锁屏 5 分钟再打开 | 还是绿的、数据是最新的 |
| 8 | 两个端同时敲同一行的同一个字段 | 后写覆盖先写，但不会丢数据（服务端把写请求排了队） |
| 9 | 电脑版点「生成共享缩略图」 | 手机【日志】里出现「⏳正在生成共享缩略图」和进度、最后「✅完成」 |

### 5.3 开发自检（改了代码之后）

```bash
pnpm run compile            # 改了 src 下的 .ts 必须做，然后重启服务
pnpm run check:parity       # 编号/字段规则前后端一致
pnpm run check:server       # 服务端纯模块（推送/队列）34 组用例
pnpm run check:mobile       # 手机版 DOM id + SSE 事件名对齐
pnpm run check:longtask     # 长活儿接缝（VS Code 侧老语义）
node scripts/e2e-web-realtime.cjs    # 端到端：跨端同步 / 有改动 / 并发写（要服务在跑）
node scripts/e2e-web-tasks.cjs       # 端到端：长任务进度（要服务在跑）
```

改 `src/webview/mobile/*`（手机版三个文件）**不用编译**，手机上刷新即可。

## 七、坏了看哪里

浏览器打开 **`http://<地址>:<端口>/api/ping`**，它会把服务端状态直接回给你：

| 字段 | 怎么看 |
| --- | --- |
| `imageDirReady` | `false` = 图片根目录没配或不存在 → 看图相关的都会报错 |
| `tokenRequired` | `true` 时所有 `/api/*` 都要带 `?token=口令` |
| `eventClients` | 手机到底连上没有。`0` = 一个实时连接都没有 → 看手机端提示 |
| `writeQueue` | 写队列深度。一直 >0 = 有写卡住了（多半共享盘慢） |
| `tasks` | `running` / `waiting`：重活是不是在排队（「点了没反应」多半是这里） |
| `dataVersion` | 电脑版改了库时它应该会变；不变说明服务端没看见外部改动 |

| 现象 | 八成是 |
| --- | --- |
| 手机打不开页面 | 服务没跑 / 不同网段 / 防火墙 / IP 变了 |
| 能打开但图全是空白 | `imageDirReady`；图片根目录下是不是"每个商品一个子文件夹" |
| 别人改了这边不变 | 底部灯什么颜色？`eventClients` 是 0 吗？ |
| 电脑版改了不提示 | `/api/ping` 的 `dataVersion` 变不变 |
| 点了生成没反应 | `/api/ping` 的 `tasks`；在排队就等 |
| 删图删不掉 | 多半别的机器正占着那张图，等几秒重试（封面最容易被占） |

## 八、几个"提前知道就不踩"的点

1. **服务只在这台机器上跑**：那台机器关机/休眠/退出，手机就打不开。
2. **电脑版的「撤销」是整库回滚**：它会把手机刚写的一起覆盖回去。用手机改完数据后，电脑版那边先别急着撤销。
3. **同一个库最好只有一个地方在写**：电脑版也开着同一份 `shop.db` 时，靠 SQLite 的文件锁 + 10 秒忙等兜底，超时会**明确报错**（不会静默丢数据）。
4. **手机端目前没有"出图"入口**（九宫格/星标总览要在电脑版做），但服务端已经具备排队与进度推送。
5. **token 默认关着**：局域网里谁都能打开。要上锁就在配置里写 `"token": "口令"`，手机第一次用 `http://<IP>:端口/?token=口令` 访问（口令会记在浏览器里）。
6. **"电脑还是手机"不靠猜**：悬停反馈按 `@media (hover:hover) and (pointer:fine)`（说的是输入设备）、
   双击按 `dblclick` 事件（本来就是鼠标产生的）、抽屉按 `min-width: 820px`（说的是空间够不够）。
   一条 `navigator.userAgent` 都没用 —— iPad 会把自己报成 Mac，那是最不可靠的判据。
7. **手机上"快点两下"和"慢慢点两下"都能进编辑**：快速双击的那一下本来会被"禁双击放大"吃掉，
   现在被我们顺手当成第二拍用掉（见 `app.js` 的 `touchend` 那段与 `tapCell`）。
