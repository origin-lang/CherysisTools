# 🏪 商品店铺管理（shopTool）

> 设计稿 v0.2：v0.1 决策已谈拢；v0.2 已实现「行内编辑 / 列头筛选+回车应用 / 清除 / 右键复制行·表 / 列表与画册字段显隐分开持久化 / 上传图片自动改名 / 商品粘贴导入 / 品类 datalist 联想」。
> 逐轮功能/技术变更归档见 [shopTool-archive.md](shopTool-archive.md)。

## v0.1 已敲定的决策

- **编号**：统一 `L+数字`（**3 位补零，最多 4 位、≤9999**）：`L7→L007`、`L76→L076`、`L999→L999`、`L1044→L1044`。X/R/裸号是历史遗留，不再产生（导入遇到按未匹配列到日志，可手工处理）。
- **同天同编号重复录/重复导入**：录入与导入时**给用户三选**：`覆盖`（用新值）/ `累加`（新旧相加）/ `跳过`（保留旧的），导入时一次选一个模式应用到全部重复行。
- **月结**：先**手动填**「本月到账收入 / 本月其他支出」，系统再**自动算**「货成本(Σ净卖×进价快照) / 利润」，确认后**归档锁定**当月，可解锁重做。多月可对比。
- **收入口径**：`income_amount` 填什么数字（结算到账 vs 订单金额）由商家自己掌握，系统只存不评判，`[待确认#4]` 关闭。
- **库存落库直读（`products.stock_manual`）**：v0.1 原定「打开/变动时现算 Σ入库−Σ卖出+Σ退款」，已改为单列落库。写入路径：补货入库/删入库自动增减；「销售自动扣库存」（`sales_deduct_stock`，默认开）开启时录/改/删销售按 `卖出−退款` 增减；双击库存列清点直接写实存。不会减到负数（`MAX(0,…)`）；库存低于阈值列红字提示补货。
- **品类**：商品新增 `category` 字段（手链/项链/耳环/手镯…自由填），与 `series`（平台 A/B/C/D/E 类链接）双维度分组筛选。分类对面料效果：「铜合金锆石手链」「铜合金仿珍珠项链」这类命名里去掉重复修饰后，首码即品类。
- 图片一个商品一个文件夹、`{code}_{时间戳}.jpg`（上传自动改名，同秒重复加 `_2/_3` 后缀），`文件夹里最早一张` 为封面；列表/画册懒加载，点开看全部图。「清空图片夹」删除该商品文件夹下全部文件（真删，需确认）。列表的「图片」列固定显示在**采购链接的前一列**（收藏列隐藏时排在最后）。封面与放大看图都走 **base64 按需下发**（与 lightbox 同一机制），不依赖 webview 资源白名单——任意图片目录都行、上传/清空后即时生效、无需重开面板。
>

## 一句话

给商家用的「商品档案 + 库存 + 每日销售 + 月度盈亏」小系统：`Lxxxx` 唯一编号管一个**款式**，可反复补货；每天记「某编号卖出/退款多少件」库存自动减；每月结一次账归档，多月能对比。

## 数据模型（db.ts）

- `products`（商品/款式）
  - `code` TEXT 唯一 —— 规范化编号（**3 位补零**，`L0076→L076`、`L76→L076`）；`name`
  - `category`（品类：手链/项链/耳环/手镯…自由填）、`series`（平台 A/B/C/D/E 类链接，可空）、`grade`（等级，映射售价规则）
  - `cost_price`（进价）、`sale_price`（售价=按等级规则自动算，可手动覆盖）、`price_manual`（0/1，手动覆盖后不再被规则重算）
  - `purchase_link`（采购链接）、`status`（0 在售 / 1 下架）、`remark`、`created_at`、`stock_manual`（当前库存，落库直读，见下方「库存口径」）
- `sale_rules`（售价规则表，按 grade 唯一）
  - `grade`、`label`（等级名）、`expr`（公式，`cost` 代指进价：`cost+10` / `cost*1.5` / 自定义 `cost*2+5`）、`tail_mode`（raw/round/p99/p88/custom）、`tail_value`（custom 用的尾数）
  - 售价值 = 表达式结果再套尾数策略；单商品 `price_manual=1` 时不再重算
- `stock_in`(入库/期初)：`product_id`、`qty`、`date`、`remark`
- `sales_record`（每日销售）：`product_id`、`date`(YYYY-MM-DD)、`sold_qty`、`refund_qty`、`cost_price`(进价快照，记账时冻结)、`note`
  - 唯一索引 `(date, product_id)`：重复录/导入时按用户选的模式处理（**覆盖 / 累加 / 跳过**）
- `monthly_settle`（月结归档，`YYYY-MM` 主键）：
  - 手动填：`income_amount`（到账收入，口径商家自定）、`extra_expense`（运费/佣金/杂支）
  - 自动算：`goods_cost` = Σ((卖−退) × 快照进价)、`sold_total`、`refund_total`
  - `profit` = income − goods_cost − extra_expense；`locked`(锁定当月 sales_record，可解锁重做)
- `settings`（key-value，**共享库**）：只剩三个全组共用的业务规则 —— `name_template`(完整名称模板)、`stock_alert`(库存预警阈值)、`sales_deduct_stock`(销售自动扣库存，默认开)。另有一个历史遗留的 `image_dir` 旧值，仅作本机 VS Code 设置未配时的回落。
  - **个人偏好已全部搬出本表**，改存本机 VS Code `globalState`（`%APPDATA%\Code\User\globalStorage\state.vscdb`），各人各设、永不写共享盘：`row_height`、`font_size`、`col_visible_list` / `col_visible_gallery`、`col_image_list` / `col_image_gallery`、`col_show_ops`、`import_fields` / `import_mode` / `export_fields`、`live_out_dir`、`live_grid_label`、`star_label_options`、`star_grid_mode` / `star_grid_cols` / `star_grid_rows`，以及只读开关 `readOnly`。
  - 分流点单一：读写都走 `index.ts` 的 `getSetting` / `setSetting`（`LOCAL_PREF_KEYS` 判定），handler 一律用 `h.getSetting` / `h.setSetting`，直接 `db.getSetting` / `db.setSetting` 会绕过。旧值留在表里不再读取。

**库存口径 = `products.stock_manual`，落库直读**（`getProductsWithTotals` 把该列作为 `stockTotal` 下发）；写入由「补货入库 / 删除入库 / 销售（开关开着）/ 清点」维护，`MAX(0, …)` 保证不为负。

## 页面（4 个 Tab）

1. **商品管理**：列表视图（行=款式：封面缩略图+编号+名称+系列+等级+进价+售价+库存+状态；点封面/按钮懒加载看全部图）+ **画册视图**（封面墙+可配置的关键字段卡）。**行内双击编辑**（改动即存）、**列头随时筛选**（输入后按 **Enter** 才应用，「清除筛选」一键还原，回车/下拉是应用时机；**编号列可输范围**：`A1~A33` / `1~33`（A 段）/ 逗号多段 `A1~A33,L1~L22` 取并集；单值带字母按精确编号 `L1`→L001，纯数字/文本按子串）、**右键复制整行 / 整表（当前筛选结果）**、**字段显隐**（列表与画册两套独立持久化设置；「字段显示」弹窗只显示**当前视图**的那一份，不再两组混排）。库存低于阈值标红「该补货」。下架行置灰整行。**「导入商品」**按钮支持整表粘贴导入（含表头的行会在**任意位置**自动整行跳过）。**「＋ 新建商品 / 行内编辑品类」输入框为 datalist 联想（5 个预设 + 现有品类 + 自由输入）。**
2. **每日销售**：
   - 手动录：日期（默认今天）+ 选/输编号 + 卖出数 + 退款数，一行一条
   - **批量粘贴**：文本框 `编号<TAB>卖出<TAB>退款` 每行，回车即批量 upsert，库存自动变；文件/表区域中间夹表头行会自动跳过；解析完的 `pasteHint` 会列出「新增/更新/跳过/未匹配/无法解析行」明细
   - 表格/剪切板导入走「通用列映射」对话框（第一期只做粘贴解析，列映射导入预留接微信） `[待确认#3]`
   - **表格行**：勾选框（首列）+ 表头全选 + 标题栏「🔄 刷新 / 删除选中」按钮；表头为 卖出数量/退款数量/净售数量/进价快照（快照带 tooltip：记录当天成交进价，之后改进价不影响历史月报）；**任何录入/粘贴/删除后表格自动刷新**，不必再手动操作
   - **销售趋势**：选「全部 / 单个商品」+「按天 / 按月」，柱子=净售（悬停看明细）；按「按日」须选月份
3. **分析·月报**：点「生成 YYYY-MM 月报」→ 填到账/支出 → 自动算货成本与利润 → **归档锁定当月**。多月对比表 + 净利润柱状图。
4. **规则与设置**：售价规则表（增删改；导入/新建/改等级时若该等级**没有规则会自动套一个默认规则** `cost*1.5→+0.88`，避免售价=成本）、完整名称模板（如 `{name}+{series}{grade}+{code}`，生成后一键复制去平台上链接）、图片根目录、预警阈值。

## 关键流程

- **新建商品**：填 编号/名称/系列/等级/进价 → 售价按等级规则自动算（可改）→ 库存 0。期初有货就补一条入库。
- **补货**：`stock_in` 加一条 → 库存自动 +n（采购订单模块是「总采购」，不打通，两套独立账）。
- **每日记录**：录/粘/导 → 该款库存按 `卖出−退款` 自动增减（「销售自动扣库存」关闭时只记账、不动库存；退款=负数卖出，库存加回）。记录里存下「当时进价」。
- **下架**：status 置 1 → 行置灰、历史销量和盈亏保留；图片文件夹可一键「清空（可选，默认不清）」。
- **月结**：锁定当月销售只读（防乱改）→ 生成不可变月报 → 后续月照旧，31 个月报表可互比。

## 使用注意

- **重复录/导入默认「累加」**：界面上的「当天已有记录时」默认选的是累加（也可改成覆盖/跳过）。
- **图片目录与封面**：封面和放大看图都是 base64 下发（和 lightbox 同一机制），**选完图片目录立即生效，不用重开面板**；上传图片复制进当前目录后立即生效。
- **工具间切换 / 重开面板自动续**：切到别的工具再回来、或重开工具集面板，会自动重新读取 SQLite 数据并回到上次用的工具；若仍显示「无商品」先看下方运行日志有没有报错。
- **数据库文件**：`shop.db` 与 `procurement.db` 同目录（`cherysis.storageDir` 指定，默认全局存储）。改后端 `index.ts`/`db.ts` 需 `pnpm run compile`；改 `client.js`/`fragment.html` 直接 F5 重载。
- **月结锁定**是「当月销售记录只读」的软锁：锁定后保存/删除/粘贴当月的销售会被拒绝，需先解锁。删除月报不会删除销售记录。
