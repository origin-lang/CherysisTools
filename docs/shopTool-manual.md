## 1. 快速开始

打开面板后先看到「商品管理」，顶部有 **三步开始使用** 引导（首次可见，可收起）：

1. 先在命令面板（`Ctrl+Shift+P`）执行 **`Cherysis:设置商品图片根目录`** 选好图片目录 —— 商品图和直播排品取图都要用它（每人各设一次，见 §6.2）；
2. 到「**商品管理 → ＋ 新建商品**」或「**导入商品**」粘贴表格建立档案；
3. 回到「**每日销售**」录入卖货，直播前到「**直播排品**」排九宫格。

五个页签（子 tab）：

| 页签        | 作用                                |
| ----------- | ----------------------------------- |
| 商品管理    | 商品档案、图片、导入/导出、批量操作 |
| 每日销售    | 当日卖货录入、批量粘贴、销售趋势    |
| 分析·月报   | 按月对账、封账、净利润图            |
| ⭐ 直播排品 | 画册星标选品 + 九宫格出图           |
| 规则与设置  | 售价规则、店铺偏好、数据库备份/恢复 |

## 2. 商品管理

### 2.1 两种视图

- **列表**：表格，行首**勾选框**，行内快捷按钮：📋 复制完整名称、📦 补货入库、🗑 删除（含记录）；
- **画册**：卡片铺开，点卡片右上 ⭐ **收藏到直播备选**，点卡片可看大图。

> 列表和画册的**显示列可分开设置**（「字段显示」按钮）。

### 2.2 字段显示（所见即所得）

「**字段显示**」里勾选哪些列，就同时决定：

- **列表展示**的列；
- 勾选批量「📋 复制选中」的表格内容（含表头）；
- 「📤 导出Excel」的导出列；
- 「导入商品」要求的列顺序。

> 规则：**编号永远是第 1 列**；库存/销量/状态是自动统计列，不受「字段显示」控制、也不参与导入。

> 字段按「① 商品档案（编号/名称/品类/系列/等级/采购链接/图片）· ② 价格与销售（进价/售价/库存/累计售出/累计净售）· ③ 状态与辅助（状态/备注）」分组勾选；列表视图的③里还有「**操作列**」（星标/复制完整名称/补货入库/删除快捷按钮），同样可以关掉。「**导出Excel**」弹窗的列选择也按同一分组排布。

### 2.3 筛选 / 排序 / 分页

- **列头筛选**：编号/名称是文字框（输入即过滤），品类/系列/等级是下拉（选项随列当前数据自动生成）；进价/售价/库存/累计售出/累计净售/状态/采购链接**没有**列头筛选；
- **编号框支持范围**：含 `~` 时按「字母+数字区间」筛，如 `A1~A33`＝A001~A033、`a1~a33` 同理（大小写不敏感）、`1~33`＝**A 段** A001~A033（两端都不写字母就按 A 段）；`~` 两侧空格可忽略（`A1 ~ A33` 等价）。逗号（`, ， 、 ; ；` 或换行）分多段，**多段取并集**：`A1~A33,L1~L22` 两段一起列出。
- **编号框的三种写法**（都不含 `~` 时）：**带字母的单值按精确编号**——`L1`＝L001、`A7`＝A007、`l007`＝L007（自动补零，与库里编号同一口径）；**纯数字仍按子串**——`7` 命中所有含 7 的编号（`L007`/`L017`/`L070`）、`007` 同时命中 `A007` 与 `L007`；**文本按子串**——`A` 命中所有 A 段。注意 `L10` 现在是**精确**的 L010（不是「所有 L1 开头」），要「所有 L1xx」请写 `L1~L199`。
- **写错会标红**：`A33~A1`（区间反了）、`A1~33`（字母只写一边）、`A1~L33`（两侧字母不一致）、`A1~A12345`（超 4 位数字）这类写法**0 结果且筛选框标红**（不静默出空表），鼠标悬停看得懂原因；
- **状态** 用表头上方（工具栏）的「全部状态 / 在售 / 已下架」下拉筛选；
- 点表头文字可排序（再点反序）；点击任意数据行可**高亮定位**当前行；**有任一筛选生效时**状态下拉旁边出现「清除筛选」按钮，点击一键清掉全部筛选；
- 结果多时分页（分页**贴底居中**，表格区域自动撑满剩余高度，更大更好滚动）；结果为空时自动隐藏分页；同一套筛选同时作用于画册与导出。

> 顶栏按钮按「视图 ｜ 字段 ｜ 筛选 ｜ 星标」分组，右侧是「新建/导入 · 撤销/重做」；列表操作提示收在「规则与设置」标签里（平时不占视线）。改格子/星标/库存会自动刷新数据，**列表滚动位置原地保留**，不会弹回顶部；切页时从当前页继续滚动。

### 2.4 新建 / 导入 / 导出

- **＋ 新建商品**：弹窗逐项填写，编号为 **1 个字母前缀 + 数字**（如 `L007`、`A007`），纯数字自动补 `L` 前缀；编号框打开时预填该前缀当前最小未用号，随输入前缀实时提示「当前最小未用」（每前缀独立、填空号，满 9999 提示换前缀）。
- **导入商品**：从 Excel/记事本**整列粘贴**，弹窗顶部会按当前「字段显示」列出列顺序，要点：
  - 每行一个商品，列序＝当前显示的可写列，**编号永远是第 1 列**；
  - 分隔可用 **Tab / 空格 / 逗号**；
  - 只贴「编号」也能建（其余走默认值）；
  - **名称里不要带空格**（空格按列分隔）；
  - 库存、销量、状态自动统计，**不用填、也不导入**（库存想改就双击库存列手动清点，见下）；
  - **已有编号 → 覆盖更新**（只更新本行列里填了的可写列；没填/没排到的列保持原样；**等级或进价变了，售价会按规则重算**，手动价除外）；
  - 粘贴后点「**解析预览**」：预览只算、不落库，直接在粘贴框**下方**显示（不再跳走）——顶部汇总将被**新增/更新/跳过**及「无法解析」行（可展开看原文），表格逐行列真实变化（如 `售价: 9.9→12.00`）；确认无误点「**确认导入**」才真正写库；**导入方式用顶部 Tab 切**（切完自动按新方式重预览），再改粘贴内容/勾选字段会自动作废旧预览、需重新解析；**同批粘贴里重复编号只取第一条**，其余自动计入「跳过」并标注「重复编号 N 行已忽略」。
- **📤 导出Excel**：导出**当前筛选结果**（未筛选=全部），列跟随「字段显示」，状态列显示「在售/已下架」。

#### 字段校验规则（新建 / 双击编辑 / 导入 共通）

| 字段           | 规则                                       | 超长处理 |
| -------------- | ------------------------------------------ | -------- |
| 编号           | 1 个字母前缀 + `1~4位数字`（纯数字默认 L 前缀），统一大写、补零到 3 位、≤9999；不允许重复；**每前缀编号独立**（`A001` 与 `L001` 可并存） | —        |
| 名称           | 必填、**不含空格**、≤100 字                | 截断     |
| 品类 / 系列    | **不含空格**、各 ≤50 字（可空）            | 截断     |
| 等级           | `0`=自定义（售价手动定），或整数 1-99      | —        |
| 进价 / 售价    | 数字、≥0，统一保留 2 位小数                | —        |
| 库存(双击清点) | 非负**整数**                               | —        |
| 采购链接       | **不含空格**、≤500 字（可空）              | 截断     |
| 备注           | ≤200 字（可含空格）                        | 截断     |

- 非法输入（名称空/含空格、负数、等级出界、库存小数…）→ **拒绝并 toast/日志提示**，不写库；**前端和入库前各拦一道**。
- 编号**只做首尾去空格**再认「1 个字母紧跟数字」，中间带 `-`/`_`/空格等分隔符的一律报格式错（不悄悄剥）。
- **改号时会同步改图片文件夹名**：目标文件夹不存在→整夹改名；存在但为空→拆壳后挪入；**存在且有内容→本次改号取消（编号不保存）**，弹窗 + 日志提示你先清空目标文件夹后重新改号即可。改号成功时夹内以旧编号开头的图片文件名（`旧编号_时间戳.jpg`）会一起改成新编号前缀（`新编号_时间戳.jpg`）。
- 销售「快捷录入」：卖出/退款需为非负整数且至少一个 >0。

### 2.5 库存（自动加减 + 手动清点）

- **自动**：`📦 补货入库` 库存 `+`；`每日销售` 卖出 `−`、退款 `+`；删销售/删入库记录也会回退对应数量；
- **手动清点**：随手双击列表**「库存」列**，改成实际剩余数回车即存（每月盘点就这么做）；
- 库存不会为负数（最低 0）；库存预警（§6.2）、导出库存列、月报期末价值都用这个数。

### 2.5 图片

- 每类商品一个文件夹：`{图片根目录}/{编号}`；
- 上传 / 粘贴 / 拖入的文件都会自动改名为 `{编号}_时间戳.jpg`（如 `L76_20260905103015.jpg`，同秒重复自动加 `_2/_3`）；
- 文件夹里**最早一张**当封面缩略图；
- 点击缩略图打开大图（浮层）；浮层可看/翻该商品全部图片。
- **右键商品**出现快捷菜单：上架恢复在售 / 下架 / 清空图片文件夹（清理该编号图片夹，文件会真的删除）。
- 大图浮层里 **Ctrl+V 粘贴 / 拖入图片**都能加图；**拖画册里已经显示的图不会再有反应**（会在源头拦住并提示，真正要拖的是资源管理器/桌面里的图片文件）；后端还按内容去重，同图即便绕过去也**不会再复制一份**。
- **看图不再卡**：缩略图缓存在**本机**（见 §7.4），第一次打开会生成、之后秒开；大图直接按文件路径加载，不整张转 base64 传进页面，所以开大图基本不卡。图片在共享盘上时这个差别尤其明显。

### 2.6 批量操作

勾选多行后（或顶栏「全选」）出现批量栏：

- 批量上架 / 下架；
- **⭐ 标星 / ☆ 取消星标**：给勾选的一批商品批量标记/取消星标；
- **🔢 批量改库存**：弹窗里选「设为固定值 / 增加 / 减少」再填数量，一次应用到所有勾选商品（减少时不会低于 0，可用 ↩ 撤销）；
- 📋 复制选中（带表头的表格文本，列跟随显示列，可直接粘进表格/微信）；
- 🗑 删除选中（**同时删掉这些商品的销售记录和入库记录，不可恢复**，删除前有确认）。

勾选之后，在列表里右键任意商品行，也会多出一条「**批量操作**」子菜单，里面是同样的上架/下架/标星/取消星标/改等级/改采购链接/改库存/删除，作用对象就是当前勾选的那一批（和批量栏口径一致，右键在哪一行不影响范围）。批量栏里已有的「📋 复制选中」「✕ 取消」不在这个子菜单里重复一遍。

内建安全网：**任何删除/关键改动的操作前会自动在 `backups/` 生成前置备份**（见 §7），反悔可恢复。

### 2.7 星标（通用标记）

⭐ 现在是**通用标记**，不只是直播用的：列表尾巴一列、画册卡片右上角都能点一下标记/取消。

顶栏只有一个「**⭐ 星标 ▾**」下拉（点它弹菜单，四项）：

- **只看星标（N 个）**：只显示打星的商品（点同一个菜单项再取消）；有星标筛选时菜单项前带 ✓；
- **复制星标清单**：把全部星标商品按当前可见列复制成表格文本（带表头，不依赖勾选/筛选）；
- **星标总览图**：把星标商品封面**拼成总览图**——默认**自动密度**（≤9 款用 3×3，更多按 4×4/5×5…；每格底下标 `编号＋售价`）。预览弹窗顶部可改「**每张排版**」：选 `3×3 / 4×3 / 3×4 / 4×4 / 5×5` 或「自定义」填行×列，**改动即按新排版重新出预览**，满意后点「✅ 生成」——**每次都会直接弹出文件夹选择框**（同「导出 Excel」，不默认上次目录），选好目录即写盘，完成后自动打开输出文件夹，弹窗内也能「📂 打开文件夹」；没有星标时「生成」按钮置灰，不会进入生成状态；
- **取消全部星标**（有确认）。
- 弹窗预览可 `‹ 上一张 / 下一张 ›` 翻页；排版一经固定每张不再自动膨胀，末页不满留空。
- 无论从哪儿触发（右键菜单、弹窗内改排版），弹窗都是**先弹出来 + 转圈 + 报「正在按…排版第 1 张…」**，图随后填进去 —— 共享盘上渲染慢也不会让人以为没点上。
- 预览用的是**本机 512px 小图缓存**（不是共享盘原图），所以改排版、翻页、反复开关弹窗都很快；第一次遇到没缓存的图会慢一点（边缩边写缓存），之后就快了。缓存放在本机 `…\globalStorage\faye.cherysis\shop_thumbs\`，改图会自动重算。**点「✅ 生成」写盘仍然用原图**，成品清晰度不受影响。

其他入口：列表尾巴一列和画册卡片右上角都能标记/取消单个星标；批量勾选后能用批量栏的「⭐ 标星 / ☆ 取消星标」一次标多个。「取消全部星标」只在「⭐ 星标 ▾」下拉里。

> 提示：**弹窗点空白处不会关闭**（避免误点丢失内容），统一用弹窗按钮或 `Esc` 关闭；右键菜单例外，仍可点外部关闭。

- 画册卡片可显示 `编号 / 售价 / 进价`（「字段显示」里勾选）；
- 直播排品的备选池**继续用同一份星标**（见 §5.1）。

## 3. 每日销售

### 3.1 快速录入

选**日期** → 填 **编号**（`L001` 或 `L076`）→ **卖出件数 / 退款件数** → 备注（可选）→ 「**录入/更新**」。

**当天已有记录** 时按顶栏「去重模式」处理（鼠标悬停有说明）：

- **累加**（默认）：把这次的量加进原记录；
- **覆盖**：用这次输入直接替换原记录（改错数时用）；
- **跳过**：已有记录就不动。

> 每录一笔销售，对应商品**库存自动 −（卖出−退款）**、**不减到 0 以下**；真实剩货被意外（丢失、赠品等）弄乱时，去「商品管理」双击库存列改回实际数即可。

### 3.2 当日销售表

- 顶栏可🔍筛编号/名称/备注、🔄 刷新、**删除选中**（按行首勾选）；🔄 会连**封面**和**累计售出/退款**一起重取（别人的改动要靠它才看得到，§7.5）；最右边是 **`🔓 可写`/`🔒 只读`** 开关（§7.5）；
- 表内可直接改数字/备注（保存即写库）；
- 若该月已封账，当前月份销售**不能改**（见 §4）。

### 3.3 批量粘贴

从表格/记事本**整列粘贴**，每行：`编号 卖出 退款`，Tab / 空格 / 逗号都行，可只写卖出：

```
L076	3	1
L1044 2
L032,1
```

点「**解析粘贴入库**」——**常见的不规则多行文本（多行、无编号、格式乱）也能按行拆分**。提示区会显示成功/跳过/未匹配数量。

### 3.4 导出销售流水 & 销售趋势

- **导出销售流水**：选起止日期 → 导出 Excel；
- **销售趋势**：选「全部商品 / 某个商品」＋「按天 / 按月」→ 刷新出柱状图；柱子=净售数量，**悬停柱子**看该时段净售与退款。

## 4. 分析·月报

本页分两个子页：**📝 本月结算**（选月份、录入、封账）与 **📊 多年对比**（列表 + 利润图）。工具栏的 `‹` / `›` / 「本月」可快速前后翻月。

三步（页面顶部有引导）：

1. **选月份** → 看「① 本月数字」（自动汇总当月销售流水 + **期初库存**＝上月结存，自动带出）；
2. 填 **三个手填数字**（成本不用乘，全部按你实际数填）→ 「**保存月报**」：
   - **到账收入** ¥（实际结算到账）；
   - **本月进货支出** ¥（小荷包里的转出数）；
   - **杂项支出** ¥（快递、氧化袋等）；
   - **期末库存金额** ¥：**自动算**＝各品（库存数量 × 进价）之和，不用填。想让它准，先回「商品管理」双击库存列把实际剩货清点改好，再回来保存；
3. 对账没问题 → 「**锁定本月**」**封账**：锁定后当月销售记录不能再改、月报数字固定，防止对账后反悔；要改销售先点「解锁」。

保存/查看时利润区会给**三种口径**（同一组手填数换着算）：

```
现金流（钱袋子）    = 到账 − 进货支出 − 杂项支出
净资产口径（含库存)  = 到账 − 进货支出 + 期末库存 − 杂项
净利润（结转期初）   = 到账 − 进货支出 + 期末库存 − 期初库存 − 杂项
```

- **净利润** 是存档口径（月报列表、净利润曲线、导出 Excel 都用它）；后两种只作参考。
- 「期初库存（上月结存）」自动＝上月保存的「期末库存金额」；没填则 0。

其他：

- 「删除该月报」只删月报数字，**不影响销售记录**；
- **📊 多年对比**子页里：
  - 「**月报列表（多年可对比）**」：历史月份汇总一览（含进货/期初/期末），**按年份分组**并在每年末尾给出「YYYY 合计」小计；「**同比**」列＝与去年同月净利润之差（▲ 涨 / ▼ 跌，无去年同月数据显示 —）。列表里点某月「查看」会载入该月并自动跳回「📝 本月结算」；
  - 「**净利润**」：各月净利润曲线；
  - 「📤 **导出Excel**」：导出全部月份月报汇总（导出内容不受分组影响）。

## 6. 规则与设置

### 6.1 售价规则

表格按等级配置，存的就是 CSV 那几项：

| 列           | 说明                                          |
| ------------ | --------------------------------------------- |
| 等级         | 行标题（如 2 级）                             |
| 公式         | `cost=进价`，按进价自动算售价，如 `cost*2.91` |
| 尾数策略     | 算完后的取整/抹零策略                         |
| 自定义尾数   | 尾数策略选中自定义时用的值                    |
| 示例(进价10) | 用进价 10 演示公式结果的预览                  |

- 「＋ 新增等级」加行、改完点「**保存规则并重算售价**」——**会用新规则重算所有商品售价**（有确认）。

### 6.2 店铺设置

- **完整名称模板**：控制「复制完整名称」和面单/表格用的完整名称。可用变量：
  `{name}` 名称 · `{category}` 品类 · `{series}` 系列 · `{grade}` 等级名 · `{code}` 编号
  下方有「实时预览」。
- **库存预警阈值**：库存 ≤ 该值且**在售** → 列表标红提示补货（0 关闭）。
- **列表行高** / **表格字体大小**：调整商品/销售/月报等表格的疏密与字号（13px 默认），即时生效并记住。

> **商品图片根目录不在这一页**，它是「跟人走」的本机设置，入口在命令面板 —— 见下。

#### 商品图片根目录（每人各设一次）

同一份数据库被多人共用时，**每个人机器上的路径写法不一样**（`Z:\商品图片` / `Y:\商品图片` / `\\NAS\share\商品图`），路径存进数据库就变成「全组一份、最后改的人覆盖所有人」。所以它**不进数据库**，而是存在各自的 VS Code 设置 `cherysis.shopTool.imageDir`：

- **设置方式**（二选一）：
  1. 命令面板（`Ctrl+Shift+P`）执行 **`Cherysis:设置商品图片根目录`** → 弹文件夹选择器，选中即写入；
  2. 直接在 **设置** 里搜 `cherysis.shopTool.imageDir` 手动填绝对路径。
- **重置**：命令面板执行 `Cherysis:重置商品图片根目录`（会告诉你清完会回落成什么）。
- 填好后**只影响你这台机器**，各改各的、互不覆盖；**改完需重开工具面板**才生效。
- 老用户不改也能继续用：库里的旧值仍然生效（历史遗留的全组共享值），但**一旦你设了自己的值，库里那个共享旧值会被自动清掉**。
- ⚠ **必须是绝对路径且真实存在**。配错（相对路径、目录不存在、写了别人机器上的路径、共享盘掉线）时本机**不能显示/上传/删除图片**，会在改动的瞬间弹一条通知提醒；打开工具面板时也会在**日志区**写一行说明（正常配好时不会写）。
- ⚠ 该键是**窗口级**设置：多人用同一个工作区文件夹打开时，建议只写在**用户设置**里，别提交到 `.vscode/settings.json` —— 那会把所有人的路径统一成同一个。此时执行设置命令会先提示「被工作区覆盖」，写入不生效。

### 6.3 数据库备份 / 恢复（＝导入数据库）

- 「**备份数据库**」：选一个**目录**，生成完整 `.db` 快照文件（含当前未落盘改动）；
- 「**从备份恢复**」：选一个 `.db` **文件** → 确认 → 用所选备份**整体替换**当前全部数据；**操作前自动先备份一次**（安全网）。

> 想"导入旧数据/换电脑搬数据"，就是：在旧机器/旧库做一次「备份数据库」→ 新机器点「从备份恢复」选那个文件。备份弹的是“选目录”、恢复弹的是“选文件”，别弄混。

### 6.4 录入与命名规范

- 编号统一 **`L+数字`（3 位补零，最多 4 位、≤9999）**：`L7→L007`、`L76→L076`、`L1044` 不变；
- 图片放 `{图片根目录}/{编号}` 文件夹，上传自动改名 `{编号}_时间戳.jpg`，文件夹里最早一张当封面；
- 历史遗留的 `X / R / 裸号` 不新建，粘贴解析遇不到编号就进「未匹配」列表。

## 7. 数据与备份

### 7.1 数据库位置

- 数据库文件：`shop.db`；
- 存放目录 = 设置 `cherysis.storageDir`（未填则默认 VS Code 全局存储 `…\globalStorage\faye.cherysis\`）；
- **改目录前先备份**：路径变了，旧数据不会跟过去。
- 多人共享时，**所有人这里的 `cherysis.storageDir` 必须指向同一个共享目录**（同一条记录才有共同命运）。
- ⚠ 唯独**图片根目录不在库里**，是每人各设一次的 VS Code 设置（见 §6.2）——所以各人填自己机器上的映射路径即可，不冲突。

### 7.2 单文件数据库（回滚日志模式）

SQLite 用 **回滚日志模式**（`journal_mode=DELETE`，为支持网络共享 / 多机同时用；WAL 在共享盘上不安全）。
**数据库就是 `shop.db` 一个文件，手动复制只拷它即可**，同目录不会留下 `-wal`/`-shm` 附属文件；稳妥做法是用工具里的「备份/恢复」。

### 7.3 自动 & 前置备份

- **每天首次操作**自动生成 `backups/shop_auto_时间戳.db`（保留最近 14 份）；
- 每次**关键操作（删除等）前**生成 `shop_pre_时间戳.db`（保留最近 20 份）；
- 备份目录：`{存储目录}/backups`。恢复、反悔都到这里找 `.db` 文件，「从备份恢复」选它即可。
- **「今天是否已备份」按目录各自判断**：共享目录和本机目录各备各的，谁都拦不住谁。所以多人共用时，A 同事开机备份过**不会**让 B 同事本机的那份也跳过——每个人自己的 C 盘上都会留下当天备份。若某个目录当天已备，全部跳过时不会提示。

### 7.4 缩略图缓存在本机

列表/画册/抽屉/大图里那些小图会缓存在**本机**默认存储目录下的 `shop_thumbs/`（即 `…\globalStorage\faye.cherysis\shop_thumbs\`），**不放共享盘**。

- 为什么：缓存要按图片文件的改动判断是否过期，同一张图在 A 是 `Z:\…`、在 B 是 `Y:\…`，路径写法不同，共用一份缓存会天天判定失效、互相覆写，白折腾；缓存在本机没有一致性代价，**随时可重建**。
- 什么时候重建：图片文件被改动/替换后自动重算（按修改时间+大小判断）；手工清缓存不用管，删掉 `shop_thumbs` 文件夹即可，下次打开自动重建。
- 什么时候清理：改编号、删图、清空图片、删商品时按编号删净对应的缓存；另有**满 30 天**的兜底清理（每天最多扫一次）。
- 旧版本遗留在**共享盘**里的 `shop_thumbs` 不会被自动删除，**确认新版本一切正常后可以自己删掉**。

### 7.5 多人共用：🔒 只读模式 + 🔄 手动刷新

共享盘上的数据库是 **SMB/SQLite**。多个人同时写会互抢排他锁，写事务在网络上失败就是那句 `❌操作失败：disk I/O error`。所以推荐的用法是**一台机器写，其他机器锁上只读**。

顶栏 `🔄 刷新` 右边有个 **`🔓 可写` / `🔒 只读`** 按钮，点一下切换，**记在这台机器上**（存在 VS Code 的本机设置里，别的机器看不见，重开面板还在）。

**锁上以后这些照常能用**：

- 所有读取、筛选、翻页、看图开大图
- **`🔄 刷新`**（主动拉一次别人改过的最新数据）
- **全部导出**（Excel / 复制整表 / 导出销售 / 导出结算 / 导出排品 / 备份库）
- **九宫格生成、星标总览预览与生成** —— 输出目录是**每人各设一次的本机路径**，所以各人生成到自己的机器，谁也不碰谁
- 调自己的字号、行高、字段显隐、导入导出勾了哪些列

**锁上以后这些一律不执行**（后端硬拦，不是把按钮变灰而已）：

- 新建/修改/删除商品、改库存、改上下架、改名称模板等规则
- 录入销售、删除销售记录、改台账
- 结算的建账/保存/锁定/删除
- 上传/清空/删除商品图片
- 星标、九宫格排品的增删改
- **撤销 / 重做**（整库回退，必须拦）
- 从备份恢复整库

被拦下时会有一句 `🔒 只读模式：这一步会写共享库，已拦下`。

**⚠ 共享的三个业务规则在只读下也改不了**：`名称模板`、`库存预警阈值`、`销售是否自动扣库存`。这三个必须全组一致，要改就在**开着写的那台机器**上改。

**没有自动同步了。** 以前面板每隔几秒自己去看「别的机器有没有提交过」，现在改成你要的时候点一次 `🔄 刷新`——共享盘上那个 5 秒一次的检查本身就会跟写的人抢锁，删掉更稳。想让别人看到你的改动，跟他说一声「刷一下」。

### 7.6 撤销/重做会把整库回退（多人同时写时要留意）

撤销的实现是「把整份数据库恢复到那次改动之前」。所以如果**这期间别的机器也改了库**，你点撤销会把**别人的改动一起撤掉**。现在遇到这种情况会先弹确认框告诉你：

- ⚠ **一个人写的时候这个框不会弹**（这也是本工具推荐的用法：**一台机器写，其他机器看**）。
- 两个人以上同时写同一份库才可能弹。弹窗里说清楚了会连带撤掉别人的内容，可以选择取消。
- 真的需要两个人同时大量改同一条数据时，别指望撤销，用「先记录对方改了什么」的办法，或者干脆约定分开时段。
- 撤销/重做都只在**当前这个面板开着的时候**有效（快照在内存里），关掉面板就没了。
- **`🔒` 只读模式下撤销/重做按钮是灰的**，整库回退必然要写共享库。

### 7.7 哪些设置跟人走、哪些全组共享

同一份 `shop.db` 被多人共享时，下面这些**在各人机器上本就该各不相同**：字号行高是个人审美、字段显隐看各自屏幕宽窄、九宫格输出目录是别人机器上的路径、导入导出勾哪些列因人而异。存进库里就是「**全组一份、最后改的人覆盖所有人**」——你把字号调大，同事那边也跟着变大。

所以这些**存你本机**（VS Code 全局状态，`%APPDATA%\Code\User\globalStorage\state.vscdb`，C 盘）：

| 存本机（各人各设） | 存共享库（全组必须一致） |
|---|---|
| 列表行高、表格字号 | **名称模板** |
| 列表/画册的字段显隐、图片列显隐、操作列显隐 | **库存预警阈值** |
| 导入勾了哪些列、导入去重模式 | **销售是否自动扣库存** |
| 导出勾了哪些列 | |
| 九宫格输出目录、底部标什么 | |
| 星标总览排版（自动/固定行列）、标注项与字号 | |

商品图片根目录也早就是本机的了，入口在**命令面板**的 `Cherysis:设置商品图片根目录`（§7.4）。

**⚠ 这些值不跟着数据库走**：换机器、换 `shop.db`、从备份恢复之后，本机偏好**都还在**（它压根不在库里）。反过来说，**换机器要重新设一遍**输出目录和字段显隐。库里还留着以前写进去的旧值，现在无人读取，属于历史遗留，不影响任何东西。

## 8. 常见问题 FAQ

**Q：怎么只挑某一段编号出来（批量补货/导出/上架）？**
在编号列头的小筛选框里输范围即可：`A1~A33`＝A001~A033，`1~A33` 这样只写一边字母不行；`1~33`＝A 段 A001~A033，逗号分多段 `A1~A33,L1~L22` 一起列出（并集）。只认 `~` 一个范围符，`~` 两侧空格随你打。单查一个编号直接写 `L1`（自动补零＝L001），要「所有 L1 开头」写 `L1~L199`。写法有问题（区间反了、字母只写一边、两侧字母不一致）时框会标红并告诉你原因。挑出来的结果可以直接用于「导出Excel」「复制整表」「批量上架/下架」。

**Q：删了商品/清了图片夹，还能找回吗？**
分两种，**图片不在备份里**：

- **商品**：删除前会自动生成前置备份（`backups/shop_pre_…`）。要找回：到「规则与设置 → 从备份恢复」选删除前那个备份即可（是整体替换，会回到当时状态）。
- **图片**：**找不回**。自动备份和前置备份备的都只有 `shop.db` 一个文件，图片文件夹从来没被备份过。删图、清空图片夹之前请自己先复制一份到别处。

**Q：导入时编号相同的行会怎么样？**
会**覆盖更新**：把本行里填了的可写列（名称/品类/系列/等级/进价/售价/采购链接）写到已有档案上，没填或列序没排到的字段保持原样；等级或进价变了，售价会按规则重算（手动价不受影响）。库存/销量/状态不参与导入。想整体改一批商品，直接整列粘贴覆盖即可。

**Q：导出 Excel 列和我想的不一样？**
导出/复制/导入一律跟随「字段显示」勾选的列。去「商品管理 → 字段显示」调整。

**Q：换电脑 / 换目录后数据没了？**
数据库在旧目录。先备份（生成 .db）→ 新环境填 `cherysis.storageDir` 或直接用默认路径 → 「从备份恢复」。若手动拷文件，只拷 `shop.db` 一个即可。

**Q：在线状态显示"已下架"，怎么恢复？**
商品行内「下架/上架」或右键菜单「上架恢复在售」；批量就用批量栏批量上架。

**Q：图片都显示不出来？**
先看**日志区**（面板底部）有没有写「商品图片根目录不可用 / 尚未设置」，再按顺序查：① **共享盘/网络映射盘现在还在吗**（断开的映射盘最常见）；② 你机器上的路径写法对不对（`Z:\商品图片` 还是 `\\NAS\share\商品图`）；③ 该目录是否真实存在。
因为图片根目录是**每人各设一次**的本机设置，别人的路径你用不了——执行命令 **`Cherysis:设置商品图片根目录`** 重新选一次即可。修好前本机不能显示/上传/删除图片，但**不会动到共享盘上的任何文件**。

**Q：别人设了图片根目录，为什么我这儿显示的是他的路径？**
图片根目录不再存进数据库了。库里那个旧值属于**历史遗留的全组共享值**，任何没设过自己路径的人都会回落到它。在自己机器上执行一次 `Cherysis:设置商品图片根目录`，就变成只影响你自己。⚠ 你一设，库里那个共享旧值就会被清掉，其他人没设自己路径的人会变成「尚未设置」——**所以一次只让一个人改，或者让每人各自先设一遍**。

**Q：共享盘上的图片看图很慢/一打开就卡？**
现在缩略图缓存在本机、大图按文件路径直接加载，第二次打开会明显变快。若仍然慢，通常是共享盘本身慢（网络/网线/映射盘），或者本机 `shop_thumbs` 缓存被清掉了（下次打开会重新生成一次）。

**Q：别人改了库，我这边面板一直开着，怎么才看得到？**
点顶栏 **`🔄 刷新`**。**没有自动同步了**（§7.5）——共享盘上那个每 5 秒一次的自动检查本身会跟写的人抢锁，删掉更稳。想让别人看到你的改动，跟他说一声刷一下。图片也跟着 `🔄` 一起重取。

**Q：不想让别人把我的字号/字段显隐/输出目录改掉？**
改不了了——这些**已经是各人各设的本机偏好**，存你机器上（§7.7），别人怎么调都影响不到你。真正全组共享的只剩 `名称模板`、`库存预警阈值`、`销售是否自动扣库存` 这三个。

**Q：「🔒 只读」锁上了还能干这个活吗？**
能：看、刷新、导出、生成九宫格和星标总览、调自己的显示偏好。不能：改商品/库存/销售/结算/图片/星标/排品、撤销重做、恢复整库、三个共享业务规则（§7.5）。

**Q：点撤销弹了个框，说「期间别人提交过」？**
意思是这期间别的机器也改了同一份库，而你点的撤销是「整库回退」，会把别人的改动一起撤掉（§7.6）。想撤就确定，不想撤就取消。**如果确定这几秒里只有你一个人在写**，那就是判断出了岔子，直接确定即可。

**Q：图片封面不对？**
封面 = 该编号图片文件夹里**最早一张**。调整就是把想当封面的那张做成文件夹里最旧的文件（或用最早时间戳），或清理后重传。

**Q：当月销售改不了？**
该月已「锁定（封账）」。「分析·月报 → 解锁」恢复可修改，改完记得再锁定。

**Q：库存是怎么来的？**
平时自动加减：补货入库 `+`，每日销售卖出 `−`、退款 `+`，不会减到负数；真实剩货和账对不上（丢失/赠品/漏记）时，**双击「库存」列直接改成实际清点数**——每月盘点就这样做。
