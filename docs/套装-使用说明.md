## 一、套装是什么

一套首饰（项链 + 耳环 + 手链）拍一张合影图打包卖，这就是套装。

它跟普通商品的关系是"打包"：

- **普通商品**：一个编号（`A001`）对应一个款式，有自己的进价、售价、库存。
- **套装**：一个编号（`T001`）对应**一张合影图**，它由若干普通商品的编号"组成"。

**套装编号一律用 `T` 开头**（`T001`、`T002`…），普通商品用别的字母。这样一眼就能看出哪个是套装。

三件要记住的事：

1. **套装不记库存**，详情页里也没有库存那一格。
2. **套装的进价是自动算的**（= 里面那几个商品的进价加起来），不用你填。
3. **套装的售价是你自己填的**（打包卖多少钱，你自己定）。

## 二、建一个套装

### 手机

1. 进「商品」页，点 **＋ 新建**。
2. 最上面有个 **「普通 / 套装」** 的开关，选 **套装**。
3. 编号会自动变成 **`T001`**（下一个空号）；不用管它，除非你想指定。
4. 填 **名称**（比如"珍珠新娘三件套"）和 **售价**（打包卖多少）。
5. 点 **📷 加图片**，把这张合影拍下来或从相册选。
6. 保存。

> 注意：选"套装"之后，**等级、进价、期初库存这三格会自动消失**。不是坏了 —— 套装没有这三个东西，所以不给填，免得填了也不知道填什么。

### 电脑（VS Code 面板）

一样的：新建表单里选「套装」，编号自动 `T` 开头，然后填名称、售价、加图、保存。

## 三、往套装里加商品

建好之后，进这个套装的详情页 —— 它的三个页签是这样分工的：

```
【基本信息】                 【价格库存】                 【备注说明】
名称  珍珠新娘三件套          状态  在售                   备注
品类 / 系列                  售价  ¥98
──────────────────────     ───────────────────────
子商品 · 3 件          编辑    合计进价 ¥32   合计售价 ¥110   比合计 −¥12
──────────────────────
A001  淡水珍珠耳环  12 / 39
A003  锁骨链        12 / 39
L004  手链           8 / 32
```

- **基本信息**：名称、品类/系列，以及**这一套由哪几件组成**（子商品清单）。
- **价格库存**：状态、你要填的**售价**，以及自动算出来的 **合计进价 / 合计售价 / 比合计**。
  定价就在这一页 —— 售价的正下方就是"比拆开买便宜多少"，不用来回翻。
- **备注说明**：备注。
- 进详情默认停在「基本信息」，跟普通商品一样。

### 子商品清单有"两个样子"

清单平时是**只读的干净样子**，右边只有一个「**编辑**」按钮。要改它（加一件 / 移出一件）才点「编辑」：

| | 平时（浏览） | 点「编辑」之后 |
|---|---|---|
| **点编号**（如 `A003`） | 进那个商品的详情 | 不动（要进详情先点「取消编辑」） |
| 点行的其它地方 | 不动 | 不动 |
| 左滑一行（手机） | 不动 | 露出「移出」 |
| 右键一行（电脑） | 选「移出」 | 选「移出」 |
| 加商品 | 收着呢 | 下面露出输入框 |

这样分开是为了**不误触**：平时浏览时，随便点到哪一行都不会"啪"地跳走；要动它，先明确说一声"我要编辑"。

**加一件**：点「**编辑**」→ 在下面输入框里填商品编号（`A003`）→ 点「添加」（或按回车）。加进去以后：

- 价格库存页那三个数字（合计进价 / 合计售价 / 比合计）**自动跟着变**，不用手动算。
- **同一个商品在一个套装里只能出现一次**，重复加不会加两遍。
- 加完点「**取消编辑**」退出，就回到干净样子了。

### 关于"比合计"

- **负号（−¥12）**＝ 比拆开买便宜了 12 块，这是让利，客人看得出来。
- **正号**＝ 比拆开买还贵。一般不该出现，但你要愿意这么卖也可以，系统不拦。
- 这个数字只是给你参考，**不影响售价** —— 售价永远是你自己填的那个数。

## 四、把商品从套装里移出

移出是个"要改清单"的动作，所以先点右上角「**编辑**」进编辑态，再动手：

- **手机**：在那一行上 **往左滑**，会露出「移出」按钮，点它。会问你一次"把 A003 从 T001 移出？"，确认才生效。
  （不左滑的话看不见这个按钮 —— 这是故意的，平时清单才不会一排红按钮。）
- **电脑**：在那一行上 **点右键**，选「移出 A003」。**电脑也要先进编辑态**（跟手机一个规矩：要改就先点「编辑」）。
  （平时浏览时右键不会有反应 —— 那是特意的，免得手一抖就把零件删了。）

**移出 ≠ 删除商品。** 移出只是"这个商品不再属于这个套装了" —— 商品本身还在、图片还在、还在商品列表里、还在别的套装里（如果它还在的话）。

要真的删掉那个商品，得回它自己的页面去删。

## 五、在子商品那边看「套」

如果一个商品被放进了套装，它自己那边会显示出来：

- **商品列表（画册）**：它的图片左上角有个小小的 **「套」** 角标。
- **它的详情页**：顶部会写 **「属于 T001、T002」**。

那个 **`T001` 是可以点的** —— 点一下就跳到那个套装去看。所以从商品跳套装、从套装跳商品，两头都能走通。

> 一个商品可以同时属于**多个套装**（比如那副耳环既在"婚礼套装"里，也在"日常套装"里），这时会并列写出所有编号，每个都能点。

## 六、怎么只看套装

在商品页点 **筛选**，里面有一个 **「只看套装」** 开关，打开它就只显示套装。

它跟你原来的筛选用法**完全一样**，可以叠加 —— 比如"只看套装"+"品类=耳环"，就是"品类是耳环的套装"。关掉开关就回到全部商品。

## 七、常见问题

**Q：我改了某个子商品的进价，套装的进价会跟着变吗？**
会。套装的进价永远是"现在这几个商品的进价加起来"，你改了子商品，回头一看套装那边的合计就变了。不需要做任何同步动作。

**Q：我改了子商品的售价呢？套装的售价会变吗？**
不会。套装的售价是你手填的，**不会被自动改掉**。但"合计售价"和"比合计"那两行会跟着变，方便你看现在还让利多少。

**Q：我把一个子商品删了，套装会怎样？**
删的时候会提醒你"它还挂在 T001、T002 里，会一并移出"。确认删除后，它会从那些套装的清单里消失，套装的合计也跟着重算。

**Q：套装能改编号吗？**
能，但**只能改成 `T` 开头的**。想把它改成 `A` 开头（变成普通商品）是不允许的 —— 套装和普通商品是两种东西，改个编号不该把性质也改掉。反过来也一样，普通商品不能改成 `T` 开头。

**Q：套装能放进另一个套装里吗？**
不能。套装的组成只能填普通商品。

**Q：为什么套装没有等级？**
等级是用来按规则自动算售价的。套装的售价是你自己定的，用不上规则，所以这一格不给。

**Q：Excel 导入能建套装吗？**
不能，**套装的组成关系要手工搭**（导入表里塞不下"它由谁组成"这件事，硬做容易错）。
但**导出会带上"组成"那一列**，你想核对哪些套装由什么组成，导出来看一眼就知道。
另外，导入时如果你的表里有 `T` 开头的编号行，系统会**拒绝它**并提示你手工建 —— 免得它变成"看着像套装、其实是普通商品"的东西。

**Q：套装会出现在九宫格和直播排品里吗？**
会，它就是个商品。画九宫格时会画它自己的合影图，直播排品也能排它。

---

## 八、一句话总结

> **套装 = 一张合影图 + 一个自己定的价 + 一串普通商品的编号。**
> 进价自己会算，库存不用管，售价你说了算。
