## 1. 导入商品（元数据）

- 打开「导入商品」弹窗，全选复制 `import_products.tsv` 内容粘贴进文本框，点导入。
- **预期**：
  - 日志显示「导入成功：新增 100 个，跳过（编号已存在）0 个」。
  - 列表 100 行；编号显示为 `L001`~`L100`（3 位补零）。
- 售价自动计算：等级 1 默认规则 `cost+10`、等级 2 `cost*1.5`+0.88 尾数、等级 3 `cost*2`+0.88 尾数；
     部分商品（编号能被 5 整除）为手动价 19.9/29.9/39.9/49；
     **等级 4 商品（L007/L014/L021…，编号能被 7 整除）导入时会自动创建默认规则**（cost*1.5 → p88 尾数），不再出现“售价=成本”。
  - 每隔 4 个（L004/L008/…）有采购链接，其余为空 → 可测「图片列必须在采购链接前一格」以及「隐藏采购链接后图片列移到末尾」。
- 若重复粘贴：日志应显示全部跳过。

## 2. 图片/封面（重点回归）

- 列表 & 画册视图：绝大多数商品应显示**彩色封面缩略图**（每个文件夹里最早数字排名的即封面，即 `Lxxx_1.jpg`）。
- **multi-image** 商品（编号能被 7 整除，如 L007/L014/L021…）文件夹里有 3 张图：点击缩略图 / 打开 lightbox 可左右翻页。
- **无图**商品：L050、L077 文件夹故意为空 → 缩略图应显示「无图」占位，不报错。
- **旧数据兼容**：L002 文件夹是旧命名 `L2_1.jpg`（文件夹名 L002），按数字排序仍应正常出封面；L003 是 24MB 大图 → 封面加载会慢/首次解码久，属预期（用于测 on-demand 缓存，第二次切回来应秒出）。
- 切到别的工具再切回 shopTool：封面应依然显示（重开自动恢复，不丢缓存）。

## 3. 上传 / 清空图片（即时生效）

- **上传**：把任意图片拷到桌面临时文件夹 → 选中一个商品（如 L007）点「上传」，选那个临时文件夹 → **预期**：日志显示自动改名成 `` L007_<时间戳>.jpg `` 并复制进 L007 文件夹；列表/画册里 L007 封面**立即**变成刚传的那张（无需重开面板/不缓存旧图）。
- **清空**：选中该商品点「清空图片夹」，确认弹窗 → 日志提示已清空；前端封面**立即**变「无图」。若再次上传又能秒出封面。
- 校验：打开资源管理器确认 L007 文件夹里现在是 `L007_<时间戳>.jpg`（旧命名已被覆盖删掉）。

## 4. 销售录入 / 粘贴

- **快捷区**：编号 `L001`、数量 `3` 点记录 → 「今日卖出 +3」、quickLog 显示 `L001：今日共 1 条记录，卖出 3 件，退款 0 件`。
- 同样编号 `L001` 数量 `2` 再记一次 → **默认「累加」模式**，今日合计应变成 5（下拉里默认选中的是「累加」；quickLog 显示 `今日共 1 条记录`，同一商品当天合并为一条）。
- **粘贴**：全选复制 `paste_sales.tsv` 粘贴到「粘贴销售」→ 默认累加导入。
  - **预期统计（今日）**：
    - 文件本身合计：卖出 `43` 件、退款 `1` 件；其中 **L001 出现两行（3+2），同一批内重复编号会自动忽略**（日志 `⏭本批重复行`），只计第一行 3 件，避免重复计数。
    - `pasteHint` 显示：`新增15 更新0 跳过1，未匹配：L888，无法解析 1 行：行…：ax243 2`。
    - 加上刚才手动录入的 5 件：今日累计卖出 **48** 件、退款 **1** 件；**L001 今日 = 5(手动) + 3 = 8**。
    - 月销/库存列随之变化：L001 库存 = 入库 −（卖出−退款）。
- **表格（本次新增）**：表头改为 卖出数量/退款数量/净售数量/进价快照；每行带勾选框，表头有「全选」，标题栏有「🔄 刷新」和「删除选中」按钮。
  - **刷新**：刚才粘贴后点「刷新」→ 表格立即重新加载（现在任何录入/粘贴/删除都会自动刷新表格，不再需要删一行才更新）。
  - **批量删除**：勾选 L005 与 L020 两行 → 「删除选中(N)」→ 确认 → 今日卖出 48→45，表格即时刷新。
  - **进价快照**：鼠标悬停列头/单元格有提示——它是“记录当天成交时的进价”，之后改进价不影响历史记录与月报。
- **退款列**：粘贴行含第 3 列时按退款计入，月销/库存自动扣回。
- **月结**：月报区「结算本月」→ 锁定后：再录销售/粘贴会被拒（提示已月结）。「删除月报」可解锁回滚。

## 5. 售卖规则 / 自动变价

- 打开「售卖规则」：应有 **4 条默认规则**（一级 cost+10 / 二级 cost*1.5+p88 / 三级 cost*2+p88 / **四级 cost*1.5+p88 为导入时自动创建**）。
- 若导入/新建/把商品改成没有规则的等级（如等级 4），后台会**自动创建默认规则**（cost*1.5 → +0.88 尾数）并提示，售价不会等于成本。
- 编辑等级 4 的公式（如 `cost*2.5`）→ 保存 → **预期**：所有等级 4 商品（L007/L014/…）售价自动重算；但**手动价**（19.9/29.9/39.9/49）不因公式变化而变。
- 改某商品编号/等级/成本：价格热更新。

## 6. 列表 / 筛选 / 列显隐

- 顶部筛选：按编号（输 `L007` 或 `7` 均可，自动补零）、名称/品类/系列关键字、等级、成本、售价、库存。
- **筛选改为回车触发**：输入关键字后列表不会即时变化，按 **Enter** 才应用；「清除筛选」按钮在输入时即时出现。
- 品类 datalist：输「手」应提示「手链/手掌…」。
- 列显隐（设置）：打开「字段显示」弹窗 → 现在只显示**当前视图**（列表或画册）的字段，不再混在一起；勾选切换各列，保存即生效；切到另一视图再打开会显示那一份独立配置。验证图片列填在**采购链接前一格**；取消「采购链接」显隐后图片列**移到末尾**，无空列。
- 筛选「库存≤阈值」：阈值设 `50`，导入的 100 个商品库存都是 0 → 应整页标红/低库存突出。
