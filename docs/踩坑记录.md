# 踩坑记录（别改回去）

> 从已删除的归档文档里抽出来的**不可再生**知识：踩过的坑、试过不成立的路、别回退的决定。
> 代码注释里那些「别改回去」大多源头在这里。
> 只收**跨模块、容易再犯**的；单个函数内部的坑就写在代码注释里。
> 按主题排，不按时间。

## 一、打包 / 依赖（最容易再犯，代价最高）

1. **`.vscodeignore` 里绝对不能排除 `node_modules`**
   实测排除后包只剩 646 文件 / 24 MB，`exceljs` / `globby` 及全部传递依赖被砍，**扩展激活即失败**。
   生产依赖的收集交给 `vsce-pnpm`，别自己排。

2. **唯一打包命令是 `pnpm run package`**（= `vsce-pnpm package`）。
   别用 `npx vsce package` —— 它**不会**触发 `vscode:prepublish`（编译 + 6 道自检全跳过），
   也不处理 pnpm 的生产依赖收集。

3. **两个 patch 不能少**（在 `pnpm-workspace.yaml` 的 `patchedDependencies`）：
   - `vsce-pnpm@0.1.0` —— 支持 pnpm scoped 依赖解析、不打平。**少了它打包缺 `@img/*`**（sharp 的二进制）。
   - `lazystream@1.0.1` —— 它 `require('readable-stream/lib/_stream_passthrough.js')`。
     官方 `readable-stream@3.6.2` 删掉了根级 shim，**不打补丁则扩展激活报
     `Cannot find module 'readable-stream/passthrough'`**。

4. **pnpm v11 的 pnpm 专属配置写在 `pnpm-workspace.yaml`**，写在 `package.json` 的 `pnpm` 字段里
   会被 pnpm **忽略并告警**。

5. **原生模块（`sharp` / `better-sqlite3`）绑平台与 ABI**：Windows 上打的包只能在 Windows 用；
   也别手动往 `node_modules` 塞别处拷来的 `.node`。

## 二、编译分隔（改完要不要重载，记牢）

| 改了什么 | 怎么生效 |
| --- | --- |
| `src/**/*.ts`（含 `index.ts` / `db.ts` / `handlers/*`） | 必须 `pnpm run compile` |
| `fragment.html` / `client*.js` / `main.html` | 运行时**直接从 `src/` 读**，F5 重载扩展即生效，**不用编译** |

**为什么**：前端资源是静态直出，`toolRegistry.resolveSrc()` 按 `path.join(extensionUri, "src", ...)` 读。
两条路一混就出现"改了没反应"或"忘了编译"。

## 三、VS Code webview 的限制

1. **OS 文件拖入默认被劫持**成"拖到编辑器打开"。必须**按住 Shift** 才把 `dragover`/`drop`
   放行给 webview，**插件无法绕过**。所以拖放只当次路径（放宽到整行/整卡投放 + 提示按住 Shift），
   **粘贴走剪贴板事件不受此限制，是主路径**。

2. **剪贴板里同一个文件会同时出现在 `clipboardData.items` 和 `.files`** ——
   不去重一次粘贴会写 2 张。必须按 `name+size+lastModified` 统一去重。

3. **图片走 base64 过 `postMessage`，>25 MB 跳过并提示**（webview 消息体与会话内存的约束）。

4. **`<select>` 有焦点时滚轮被当成上下键** —— 用户点过一次「画册大小」，之后鼠标划过它滚一下
   就把值改了，`onchange` 照样跑、本机偏好也被存成误触值。修法是**选完就交还焦点**
   （`installSelectBlurAfterPick`，走 `document` 上的 `change` 委托），**不要去拦 `wheel`**：
   那条路试过，商品管理页里真正的滚动容器（`#productGalleryView` / `.table-wrap`）是工具栏的
   **兄弟**不是祖先，祖先链上找不到能滚的东西，量被丢掉；`overflow:hidden` 的祖先又碰不得
   （改它 `scrollTop` 会把整个页签顶歪）。**结论：别碰滚动，只撤焦点。**

## 四、前端脚本（无框架无打包，靠约定）

1. **`client-*.js` 全部在同一个顶层作用域声明 `var` / `function`**，
   **加函数前先 grep 全文件同名** —— 同名不同参在 JS 里会被后者**静默覆盖**，极难排查
   （order1688Tool 的预览空白就是这个根因）。

2. **`fragment.html` 里的元素重画**要小心：异步回包时整块重画会把用户**正在输入**的
   `<input>` 换掉（字和焦点一起没）。已踩过两次：
   - 手机版编号筛选框（`imageStatsLoaded` 回包整块重画 `#filterBody`）→ 拆出
     `renderFilterCodeInput()`，异步只走 `refreshFilterGroups()`
   - 通用做法：**要重画的容器里如果有用户正在编辑的控件，就把它拆出来单独建**

3. **不要在 `input` 事件里实时改 `el.value`**（做输入过滤时最容易犯）：
   拼音输入时 `el.value` 是**组合（composition）中间态**，程序写一次值等于宣告组合结束，
   输入法把当前拼音直接上屏、后面的键重新组合 —— 用户看到"打字时多出好多字"。
   **要过滤就等 `blur`**；`keydown` 里要拦键也必须放过组合期（`e.isComposing || keyCode === 229`）。

## 五、数据与导入

1. **粘贴导入是按「空白」分列的**（`rowParse.ts` 的 `splitCells` 用 `[,;，；\s]+`）。
   所以 `name / category / series / purchase_link` 标了 `noSpace` —— **这不是审美要求，是导入的前提**。
   名称里一个空格，导入时那一行会从空格处劈开、**后面所有列整体错位**。
   「每日销售」的批量粘贴更是拿空格当分隔符，所以这个约定跨功能共用。
   → 要放宽它，动的必须是**导入格式**（改 Tab/引号 CSV），不是校验开关。

2. **手写全角字符很常见**（中文输入法）：编号筛选原来只认 ASCII `~`，
   用户打出全角 `～`（U+FF5E）就判成"写错"、一个都不命中。两端已加 `normalizeCodeQuery()` 归一。
   **凡是要用户手输的符号，都要考虑全角。**

3. **编号默认前缀是 A**（`pricing.ts` 的 `canonicalCode()`）。别在任何地方写死 `L`
   （手机版「用下一个空号」曾经写死 `L`，与电脑版不一致）。

4. **`column_visible` 这类个人偏好不进共享库**（存 `globalState`），
   共享库只留 `name_template / stock_alert / sales_deduct_stock`。
   放共享库会变成"最后改的人覆盖所有人"。图片根目录同理（跟人走）。

## 六、各工具特有

### procurementTool
- **组合框勿回退到 `datalist`**：键盘导航是需求硬约束，`datalist` 不满足。
  要扩"防抖加载远程厂商"，扩展点在 `buildSupplierCombo` 的 `matches` / `render`。
- **加字段联动**：`SUPPLIER_FIELDS / ORDER_FIELDS` 增列时，同步改 `buildEditor`、
  `makeAddRowControl`、`saveAddRow`、`commitInlineEdit`（右键复制的列集合是按字段定义自动生成的，不用改）。
- **撤销水位**：每动作存**全库快照**，30 条上限 = 最多回退 30 步。库存量超大时快照内存线性上涨。
- 后端 `joinList` 只有一处，改批量删除日志格式时复用它，**别在两处各写一份截断逻辑**。

### order1688Tool
- 改回 `renderPreview(rows)` 会让旧 bug 回潮（与 §四.1 同源：同名函数覆盖）。
- `ordersDump` 主流程与 runId 日志是诊断埋点，真因已修但**先别删**；
  要精简就先跑通一次「解析→入库→记录列表刷新→导出」。

### excelAnalyzeTool / nineGridTool
- 切工具保留 DOM 用**节点搬移**，**不用 `innerHTML` 字符串缓存**：
  快照会丢文件输入值与已绑定的 `onclick`，而且它们的 `init()` 会重建规则列表/网格 ——
  切回时要**避开 re-init** 才真保留。
